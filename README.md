## Sobre meu trabalho

Atuo no desenvolvimento **full stack**: construo interfaces com Flutter e Dart e desenvolvo os serviços que as sustentam, com APIs em Node.js, TypeScript e Python, modelagem e persistência de dados e integração entre as camadas.

- **Front-end:** interfaces em Flutter, com navegação, clareza das informações e experiência de uso.
- **Back-end:** APIs REST com Node.js, TypeScript, Express e Python (Flask), autenticação e comunicação em tempo real.
- **Dados:** modelagem e acesso com PostgreSQL, SQLite, Prisma, Supabase e Firebase.
- **Código:** organização por funcionalidade e separação de responsabilidades conforme o tamanho do projeto.
- **Qualidade:** testes de regras e regressões, documentação de execução e verificações com GitHub Actions.
- **Aprendizado:** experimentos em Python e estudos de inteligência artificial aplicada ao desenvolvimento de software.
